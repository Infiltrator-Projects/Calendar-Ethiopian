# Ethiopian Amete Mihret Calendar

Ethiopian chronology, dates and ICU formatting are provider-owned. The public provider ABI, generic arithmetic, and civil coordinate mechanics come from Common 1.19.80 at dc4aac326964ca4400b6e21851d16eea674040c8, compiled from its pinned submodule as one authoritative archive. Copied generic source files are removed; release installers snapshot Common for offline use and tests protect accuracy.
